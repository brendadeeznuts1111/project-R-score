# Grounded capability map

Harness SSOT for the Bun / Proton Pass capability matrix (Wave 2 JIT extract from root `AGENTS.md`).

**Bake:** `bun run bake:capabilities` → `/registry/capability-map-subset.json` · `capability-map-full.json`

**Consumers:** [`docs/packages/README.md`](../packages/README.md) · [`docs/packages/docs-index.json`](../packages/docs-index.json) · `bun run packages:docs-index`.

**Bench / profile metrics** (separate contract): [`tenants/bun-bench-profiling.md`](tenants/bun-bench-profiling.md) · `bun run bench:status`.

## Grounded capability map

Each row maps to a documented API — Bun or Proton Pass CLI — with type, version,
"Used in", status, and canonical source.

**Consumers of this map (decision tables):** packages/workspace docs index —
[`docs/packages/README.md`](docs/packages/README.md) · machine SSOT
[`docs/packages/docs-index.json`](docs/packages/docs-index.json). Regenerate
tables: `bun run packages:docs-index` · CI: `bun run packages:docs-index:check`
· re-audit dates: `bun run packages:docs-index --bump-verified`.
