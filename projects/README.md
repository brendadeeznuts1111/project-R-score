## 📋 Project Guidelines

- Each project should be self-contained
- Use relative paths for internal dependencies
- Include README.md in each project
- Follow the monorepo .gitignore rules
- Keep project-specific configurations within the project directory

## 🚀 Adding New Projects

1. Choose appropriate category directory
2. Create project directory with descriptive name
3. Add README.md with project description
4. Follow existing project structure patterns
