# Kal/Poly documentation guidance

The parent [`AGENTS.md`](../AGENTS.md) owns product commands and engineering
policy. This directory contains documentation only.

- Start navigation changes in [`DOCUMENTATION_INDEX.md`](DOCUMENTATION_INDEX.md).
- Keep examples aligned with current root or subproject `package.json` scripts.
- Label historical status, benchmark, and implementation notes as snapshots;
  do not present them as current runtime authority.
- Do not include credentials, live endpoints, or unverified performance claims.
- Run Project R documentation checks from the repository root after changing
  links or Markdown structure.
