# AGENTS.md

AI agent entrypoint for the FactoryWager monorepo (`~/Projects`). This file is
always-loaded policy. Use [`docs/AGENTS.md`](docs/AGENTS.md) for task routing;
do not preload the documentation tree.

Project R skills live only in `.agents/skills`. Validate them with
`bun run skills:validate`.

## Authority and boundaries

- `origin` is this monorepo, `project-R-score`. `cascade` is the private nested
  `cascade-mover-v3` remote and is never the default push target. Repository
  identity comes from `lib/github-repository-ref.ts`; documentation paths and
  remote parts come from `lib/docs/repo-docs.ts`.
- Repository policy owns runtime, MCP, skills, tests, and release behavior.
  Global configuration may point here but must not copy these contracts.
- `.mcp.json` is the workspace MCP source of truth. `.cursor/mcp.json` links to
  it; `.vscode/mcp.json` is generated by `bun run mcp:sync`.
- Proton Pass owns credentials. Never paste tokens into prompts or shell
  history. Route vault, Cloudflare, remote-host, and tunnel work through
  [`docs/AGENTS.md`](docs/AGENTS.md).
- Soft Balance, rails, MessageLog, phones, and package Telegram belong to
  `toc-ops-repo` (`ct`). This repository only bakes its TOC portal board.

## Mandatory code boundaries

Domain IDs are not bare `string`. Use the approved brand and constructor from
`lib/types/branded.ts` and
[`lib/types/branded/README.md`](https://github.com/brendadeeznuts1111/project-R-score/blob/main/lib/types/branded/README.md).
An intentionally opaque primary key requires `// brand-ok`; an empty branded
cast is invalid.

Parse external `unknown` once at an allowlisted wire boundary. Interior code
receives trusted domain types and must not re-decode them. The path and naming
contract is [`docs/WIRE_BOUNDARY.md`](docs/WIRE_BOUNDARY.md).

## Operating rules

- **Inspect before editing.** Run `git status` and `bun run lane:status`. Keep
  work disjoint from dirty files owned by other sessions. Status and commit age
  are observations, not ownership claims or retirement authority.
- **Use worktrees.** The primary checkout tracks `main`; feature work belongs in
  a worktree. Run `bun install` once there so Husky is wired. Copy only required
  gitignored runtime files from the primary checkout.
- **Keep the index scoped.** Commit with an explicit pathspec when another lane
  may be staging. Verify it with
  `git diff-tree --no-commit-id --name-only -r HEAD`. Never reset, restore,
  move, or delete another lane's files.
- **Keep generated artifacts separate.** Commit bakes as their own
  `chore(bake): ...` change or restore only bake paths owned by your lane.
  Ignore foreign root directories; do not delete them to satisfy hygiene.
- **Use repository quality tools.** Root quality uses pinned Prettier and
  ESLint. Nested standalone products may keep their explicitly pinned tools.
- **Use Bun's test lanes.** Development prefers `bun run test:changed` /
  `test:watch` over bare `bun test --dots`; staged gates run before commit;
  `bun run bun:ci` is merge proof. Do not introduce `bun-git-hooks` or Node-only
  flags such as `--runInBand`.
- **Deliver through a PR.** `main` is squash-only and branch-protected. Keep all
  headings from [the PR template](.github/pull_request_template.md) and run
  `bun run bun:ci` before merge. Hosted Actions are not merge authority.
- **Synchronize safely after squash.** Prefer `bun run sync:main` (backs up any
  unpushed tip, soft-resets to `origin/main`, clears soft-reset residue, leaves
  foreign untracked roots). Optional rebind so muscle memory stays safe:
  `git config alias.sync-main '!bun run sync:main --'`. Never use
  `git reset --hard` or a repository-wide restore to “clean up” after sync.
- **Record foreign failures.** If a gate fails only on another active lane,
  record its command, output, and owner. Use `SKIP_TEST_CHANGED=1` only with
  that evidence in the commit message.
- **Select release ownership.** Build, pack, channel, and publish commands must
  resolve in an explicitly selected package. Never infer the private monorepo
  root or substitute a native registry publish for the Factory artifact route.
