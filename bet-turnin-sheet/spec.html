Effect + Bun.cron Integration

Each cron job is an Effect workflow passed to Bun.cron. The runner wraps Effect in retry + logging.

TypeScript 
// Refs: B04 · E04 · E05 · E03 · SPEC-03
import { Effect } from "effect";
import { ConfigService, SheetApiService } from "./services";

const dailySummaryJob = Effect.gen(function* () {
  const config = yield* ConfigService;
  const totals = yield* SheetApiService.fetchYesterdaysTotals();
  const msg = formatSummary(totals);
  yield* TelegramService.sendMessage(config.general_topic_id, msg);
});

Bun.cron("daily_summary", {
  pattern: "0 9 * * *",
  timezone: "America/Los_Angeles",
  async run() {
    await Effect.runPromise(dailySummaryJob.pipe(
      Effect.retry({ times: 3, delay: 1000 }),
      Effect.catchAll(err => Effect.logError("Cron failed", err))
    ));
  }
});

Effect gives typed dependencies, retries, timeouts, and observability.
